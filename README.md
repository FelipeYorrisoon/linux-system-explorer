# Linux System Explorer

A Linux system inspection tool written in C to explore system information,
processes, and kernel interfaces through reproducible experiments.

The project is developed as a learning and engineering portfolio focused on:

- C programming and debugging
- Linux userspace and kernel interfaces
- Process and memory inspection
- System calls and `/proc`
- Automated testing and code quality
- Technical documentation

## Status

**In development.** The initial project structure is being prepared.

## Planned features

- System and kernel information
- Memory information from `/proc/meminfo`
- System uptime from `/proc/uptime`
- Process inspection through `/proc`
- Human-readable and JSON output
- Automated tests and continuous integration
- Documented system-call experiments using `strace`

## Requirements

- Ubuntu Linux
- GCC
- GNU Make
- Git
